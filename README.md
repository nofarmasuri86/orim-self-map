# מיפוי עצמי – בית ספר אורים

שאלוני תפיסה עצמית לתלמידים (מילולי וחזותי) ולצוות, עם דשבורד, ייצוא Excel והדפסה לפי כיתה.

- האתר: GitHub Pages מתוך `index.html`
- הנתונים: Supabase (טבלאות `sm_responses`, `sm_config`)
- הקמה ראשונית של מסד הנתונים: להריץ את `setup.sql` פעם אחת ב-SQL Editor של Supabase
- פעולות ניהול (Excel, עריכת נוסחים, מחיקה) מוגנות בסיסמה שנבדקת בשרת. משנים אותה מתוך "עריכת נוסחים ← שינוי סיסמה".
